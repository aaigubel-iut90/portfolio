Portfolio de stage — BUT Informatique 2ème année

Ce portfolio présente mon expérience de stage réalisée à la Fondation Pluriel dans le cadre de ma deuxième année de BUT Informatique (parcours Développement d'Applications) à l'IUT de Belfort-Montbéliard. 🎯 Contexte du sujet de stage

Situation existante et ses limites

Certains sites de la Fondation utilisaient le logiciel VT-Totem (VT-Design) pour afficher du contenu dynamique sur des écrans TV. Ce système présentait plusieurs problèmes :

  • Boîtiers spécifiques au coût élevé
  • Impossible de différencier l'affichage par écran
  • Réinitialisation obligatoire après coupure réseau
  • D'autres sites utilisaient des clés USB (mise à jour manuelle)
  • Aucune solution unifiée sur l'ensemble des 69 sites

Sujet du stage

Développer un outil web de gestion des affichages dynamiques administré par le service communication. La solution devait permettre de diffuser du contenu différent selon les sites, à moindre coût, via n'importe quelle télévision avec accès internet, sans boîtier dédié.

Enjeux et objectifs

  • Solution unique couvrant les 69 sites de la fondation
  • Contenu personnalisable par site et par écran
  • Administration centralisée par le service communication
  • Coût réduit : fonctionne sur n'importe quelle TV avec un navigateur
  • Affichage de médias variés (images, vidéos, PowerPoint, menus, météo…)
  • Gestion de programmes (groupes de présentations) diffusés par plages horaires
  • Authentification sécurisée via Azure Active Directory (SSO fondation)

Livrable

Une application web PHP/Symfony composée de deux services : une API REST (back-end métier) et une interface web (front-end administration), communiquant ensemble via des appels HTTP sécurisés.
